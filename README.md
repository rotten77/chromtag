# Chromtag

Chromtag is a Chrome extension that reads `#hashtags` from bookmark titles. Combine tags, folders, and a text search to find pages in your existing Chrome bookmarks.

## Install

In Chrome 157 or later, open [Chromtag in the Chrome Web Store](https://chromewebstore.google.com/detail/epeiimpoigheahfbmmhadnfgimaacipk) and select **Add to Chrome**.

## Privacy and security

Browsing and filtering are read-only. Chromtag processes bookmarks locally and does not send bookmark or search data to a server. It changes your native Chrome bookmarks only when you ask it to add, edit, move, or delete one.
